# Contributing to Machine Learning Portfolio

Thank you for your interest in contributing! This document provides guidelines for contributing to the ML Portfolio.

## How to Contribute

### Reporting Issues
1. Check existing issues first
2. Provide clear title and description
3. Include steps to reproduce
4. Attach error logs/screenshots

### Adding Projects
1. Create new project directory
2. Include comprehensive notebook
3. Add data files or links
4. Write detailed README
5. Include evaluation metrics

### Pull Requests
1. Fork the repository
2. Create feature branch: `git checkout -b feature/NewProject`
3. Add your project
4. Write comprehensive documentation
5. Test notebooks and code
6. Submit PR with description

## Project Standards

- Use Jupyter notebooks for exploration
- Include data preprocessing
- Compare multiple models
- Document results with metrics
- Add visualizations
- Write markdown explanations
